# 📋 Full Syllabus

Complete 16-module breakdown of the Full Stack Developer Training.

---

## Course Structure

| Symbol | Meaning |
|--------|---------|
| 🟢 | Beginner — no prior knowledge needed |
| 🟡 | Intermediate — builds on earlier modules |
| 🔴 | Advanced — requires solid foundation |

---

## Module 01 — HTML Structure 🟢

**Week 1** · Build the Amazon Homepage Skeleton

> **Pain Point:** "I need to build a web page. Where do I even start?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Project Setup | VS Code, file structure, first HTML file |
| 2 | Page Structure | `DOCTYPE`, `head`, `body`, `meta` tags |
| 3 | Semantic HTML | `header`, `nav`, `main`, `section`, `footer` |
| 4 | Forms & Inputs | Search bars, login forms, input types |
| 5 | Images & Media | `img`, `picture`, `figure`, `alt` attributes |
| 6 | Navigation & Links | Anchor tags, relative/absolute paths |
| 7 | Tables & Lists | Product specs, ordered/unordered lists |
| 8 | Accessibility | ARIA labels, semantic meaning, screen readers |

**Deliverable:** Complete HTML-only Amazon homepage clone

---

## Module 02 — CSS Styling 🟢

**Week 2** · Make It Beautiful

> **Pain Point:** "The HTML works but it looks terrible. How do I make it look like a real website?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | CSS Selectors | Element, class, ID, combinators, specificity |
| 2 | Box Model & Display | Margin, padding, border, block vs inline |
| 3 | Flexbox Layouts | Flex container, justify, align, wrap, gap |
| 4 | CSS Grid | Grid template, areas, responsive grids |
| 5 | Positioning | Static, relative, absolute, fixed, sticky |
| 6 | Responsive Design | Media queries, mobile-first, breakpoints |
| 7 | Pseudo-classes & Elements | `:hover`, `:focus`, `::before`, `::after` |
| 8 | CSS Animations | Transitions, keyframes, transforms |

**Deliverable:** Fully styled, responsive Amazon homepage clone

---

## Module 03 — CSS Variables & Theming 🟢

**Week 3** · Dark Mode & Theme System

> **Pain Point:** "The client wants dark mode. I'd have to change colors in 200 places..."

| # | Task | What You Learn |
|---|------|---------------|
| 1 | CSS Variables Basics | `:root`, `var()`, custom properties |
| 2 | Design Tokens | Color systems, spacing scales, typography tokens |
| 3 | Dark Mode Toggle | `prefers-color-scheme`, JS toggle, `data-theme` |
| 4 | Theme System | Multiple themes, Sass basics for comparison |

**Deliverable:** Ecommerce site with working dark/light mode toggle

## Module 04 — Bootstrap 🟢

**Week 4** · Rapid UI with Reusable Components

> **Pain Point:** "I need 100 product cards, a navbar, modals, forms... I keep copying the same CSS."

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Bootstrap Setup | CDN, npm install, project integration |
| 2 | Grid System | 12-column grid, responsive breakpoints |
| 3 | Components | Cards, buttons, badges, alerts, forms |
| 4 | Navbar & Modals | Responsive navbar, modal dialogs, offcanvas |
| 5 | Bootstrap Ecommerce | Full ecommerce page rebuild with Bootstrap |

**Deliverable:** Bootstrap version of the ecommerce site

## Module 05 — Tailwind CSS 🟡

**Week 5** · Custom Design with Utility Classes

> **Pain Point:** "Bootstrap sites all look the same. I want a custom design without writing 1000 CSS classes."

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Tailwind Setup with Vite | Vite project, PostCSS, Tailwind config |
| 2 | Utility Classes | Spacing, colors, typography, layout |
| 3 | Responsive Utilities | Breakpoint prefixes, responsive design |
| 4 | Custom Configuration | Custom colors, fonts, spacing, plugins |
| 5 | Tailwind Ecommerce | Full ecommerce page rebuild with Tailwind |

**Deliverable:** Tailwind CSS version of the ecommerce site

---

## Module 06 — JavaScript 🟡

**Week 6** · Making It Interactive

> **Pain Point:** "The Add to Cart button does nothing. How do I make things happen when users click?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Variables & Data Types | `let`, `const`, strings, numbers, booleans |
| 2 | Functions & Scope | Function declarations, arrows, closures |
| 3 | DOM Manipulation | `querySelector`, `createElement`, `innerHTML` |
| 4 | Events & Interactivity | Click, submit, input, event delegation |
| 5 | Arrays & Objects | Product data structures, destructuring |
| 6 | Loops & Iteration | `for`, `forEach`, `map`, `filter`, `reduce` |
| 7 | Add to Cart | Cart logic, quantity, total price |
| 8 | Search & Filter | Real-time search, category filtering, sorting |
| 9 | Local Storage | Persisting cart data across page refreshes |
| 10 | Async JavaScript | Callbacks, Promises, async/await |
| 11 | Fetch API | Loading products from external APIs |

**Deliverable:** Interactive ecommerce site with cart, search, filter, and persistent data

---

## Module 07 — TypeScript 🟡

**Week 7** · Type Safety & Code Confidence

> **Pain Point:** `calculate(100, "abc")` — "Why didn't JavaScript stop me?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Why TypeScript | Type errors in JS, the case for static typing |
| 2 | Types & Interfaces | Basic types, custom interfaces, type aliases |
| 3 | Enums & Generics | Enumerations, generic functions and types |
| 4 | Modules & Config | Import/export, `tsconfig.json`, compilation |
| 5 | Refactor to TypeScript | Converting the JS ecommerce project to TS |
| 6 | Advanced Types | Utility types, discriminated unions, type guards |

**Deliverable:** Type-safe TypeScript version of the ecommerce project

---

## Module 08 — React 🟡

**Week 8** · Component-Based Architecture

> **Pain Point:** "I'm writing 100 `<div class='card'>` blocks by hand. There has to be a better way."

| # | Task | What You Learn |
|---|------|---------------|
| 1 | React Setup with Vite | Create React App, project structure, dev server |
| 2 | Components & JSX | Functional components, JSX syntax, fragments |
| 3 | Props & State | Data flow, `useState`, lifting state |
| 4 | Hooks | `useEffect`, `useRef`, `useContext`, custom hooks |
| 5 | React Router | Routes, navigation, URL parameters, nested routes |
| 6 | Forms & Validation | React Hook Form, Zod validation, error handling |
| 7 | Context API | Global state, theme context, cart context |
| 8 | TSX Typing | Props interfaces, state typing, event types |
| 9 | TanStack Query | Server state, caching, loading/error states |
| 10 | React Ecommerce | Complete SPA rebuild with all features |

**Deliverable:** Full React + TypeScript ecommerce SPA

---

## Module 09 — Node & Express 🟡

**Week 9** · Building the Backend

> **Pain Point:** "Products are stored in a JavaScript array. What do real companies do?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Node Fundamentals | Runtime, modules, `fs`, `path`, `http` |
| 2 | Express Setup | Express app, routing, request/response |
| 3 | REST API Design | Endpoints, HTTP methods, status codes, CRUD |
| 4 | Middleware | Custom middleware, CORS, body parsing, logging |
| 5 | Error Handling | Try/catch, error middleware, custom error classes |
| 6 | Environment Config | `dotenv`, config files, secrets management |

**Deliverable:** RESTful API serving product, user, and cart data

## Module 10 — MongoDB 🟡

**Week 10** · Persistent Data

> **Pain Point:** "Refresh the page... all the data is gone."

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Why Databases | Data persistence, the problem with in-memory storage |
| 2 | MongoDB Setup | Atlas cluster, connection string, MongoDB Compass |
| 3 | Mongoose Schemas | Schema definition, validation, defaults, virtuals |
| 4 | CRUD Operations | Create, Read, Update, Delete with Mongoose |
| 5 | Relationships | References, populate, embedded documents |
| 6 | Indexes & Aggregation | Performance, search indexes, aggregation pipeline |
| 7 | Redis Caching | Session store, caching frequently accessed data |

**Deliverable:** Full database layer — products, users, orders, cart persisted in MongoDB

---

## Module 11 — Authentication 🔴

**Week 11** · Securing the Application

> **Pain Point:** `if(username === "admin")` — "Is this really how authentication works?"

| # | Task | What You Learn |
|---|------|---------------|
| 1 | Password Hashing | bcrypt, salt rounds, why plain text is dangerous |
| 2 | JWT Authentication | Token creation, verification, middleware |
| 3 | Refresh Tokens | Token rotation, secure storage, expiration |
| 4 | Roles & Permissions | Admin vs user, route protection, authorization |
| 5 | Session Management | Cookies, HTTP-only, secure flags, CSRF |

**Deliverable:** Complete auth system with registration, login, protected routes, and role-based access
