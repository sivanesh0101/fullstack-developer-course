# 📖 Glossary

Key terms used throughout the Full Stack Developer Training.

---

## A

- **AJAX** — Asynchronous JavaScript and XML; technique for making HTTP requests without reloading the page
- **API** — Application Programming Interface; a set of endpoints that allow software to communicate
- **Async/Await** — Modern JavaScript syntax for handling asynchronous operations
- **Authentication** — Verifying who a user is (login)
- **Authorization** — Verifying what a user can do (permissions)

## B

- **Backend** — Server-side code that handles data, logic, and APIs
- **bcrypt** — Library for hashing passwords securely
- **Breakpoint** — Screen width at which layout changes for responsive design

## C

- **CDN** — Content Delivery Network; serves files from servers close to the user
- **CI/CD** — Continuous Integration / Continuous Deployment
- **CORS** — Cross-Origin Resource Sharing; security policy for API access
- **CRUD** — Create, Read, Update, Delete — the four basic database operations
- **CSS Grid** — Two-dimensional CSS layout system
- **CSS Variables** — Custom properties defined with `--name` and used with `var()`

## D

- **Docker** — Containerization platform for consistent environments
- **DOM** — Document Object Model; the browser's tree representation of HTML
- **dotenv** — Library for loading environment variables from `.env` files

## E

- **Express** — Minimal Node.js web framework for building APIs
- **ESLint** — JavaScript/TypeScript linting tool

## F

- **Flexbox** — One-dimensional CSS layout system
- **Frontend** — Client-side code that runs in the browser
- **Fetch API** — Browser API for making HTTP requests

## G

- **Git** — Version control system for tracking code changes
- **GitHub Actions** — CI/CD automation built into GitHub

## H

- **Hook** — React function (e.g., `useState`, `useEffect`) for managing state and side effects
- **HTTP** — HyperText Transfer Protocol; the protocol of the web

## J

- **JSX** — JavaScript XML; syntax extension that lets you write HTML in JavaScript
- **JWT** — JSON Web Token; compact token for authentication
- **JSON** — JavaScript Object Notation; data format used by APIs

## M

- **Middleware** — Functions that run between request and response in Express
- **MongoDB** — NoSQL document database
- **Mongoose** — ODM (Object Data Modeling) library for MongoDB

## N

- **Node.js** — JavaScript runtime for server-side programming
- **npm** — Node Package Manager
- **Nginx** — Web server used as a reverse proxy

## P

- **PM2** — Process manager for Node.js applications
- **Props** — Data passed from parent to child in React

## R

- **React** — JavaScript library for building user interfaces
- **REST** — Representational State Transfer; API design pattern
- **Redis** — In-memory data store for caching

## S

- **SPA** — Single Page Application
- **State** — Data managed within a React component
- **SSR** — Server-Side Rendering

## T

- **TanStack Query** — Server state management library for React
- **Tailwind CSS** — Utility-first CSS framework
- **TypeScript** — Typed superset of JavaScript
- **TSX** — TypeScript JSX

## V

- **Vite** — Modern frontend build tool
- **Virtual DOM** — React's in-memory representation of the real DOM

## Z

- **Zod** — TypeScript-first schema validation library
