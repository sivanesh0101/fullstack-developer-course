# 📋 Prerequisites

Everything you need before starting the Full Stack Developer Training.

## 🖥️ Hardware Requirements

| Requirement | Minimum | Recommended |
|------------|---------|-------------|
| **RAM** | 4 GB | 8 GB or more |
| **Storage** | 20 GB free | 50 GB free |
| **OS** | Windows 10 / macOS 10.15 / Ubuntu 20.04 | Latest version |
| **Internet** | Stable connection | Broadband |

---

## 🧰 Software to Install Before Day 1

### 1. Code Editor — Visual Studio Code

Download from [code.visualstudio.com](https://code.visualstudio.com/)

**Essential Extensions:**
| Extension | Purpose |
|-----------|---------|
| Live Server | Preview HTML pages with auto-reload |
| Prettier | Auto-format code |
| ESLint | JavaScript/TypeScript linting |
| Auto Rename Tag | Rename paired HTML tags |
| Path Intellisense | Autocomplete file paths |
| Thunder Client | API testing inside VS Code |

### 2. Browser — Google Chrome

Download from [google.com/chrome](https://www.google.com/chrome/)

You'll use Chrome DevTools extensively for debugging.

### 3. Version Control — Git

Download from [git-scm.com](https://git-scm.com/)

Verify installation:
```bash
git --version
```

### 4. GitHub Account

Sign up at [github.com](https://github.com/)

You'll use GitHub to:
- Store your project code
- Track your progress
- Build your developer portfolio

### 5. Node.js (Required from Module 5 onwards)

Download LTS from [nodejs.org](https://nodejs.org/)

Verify installation:
```bash
node --version
npm --version
```

### 6. MongoDB (Required from Module 10 onwards)

**Option A** — MongoDB Atlas (Cloud, recommended):
Sign up at [mongodb.com/atlas](https://www.mongodb.com/atlas)

**Option B** — Local installation:
Follow the [MongoDB installation guide](https://www.mongodb.com/docs/manual/installation/)

### 7. Postman (Required from Module 9 onwards)

Download from [postman.com](https://www.postman.com/)

## 📚 Prior Knowledge

### Required

- Basic computer literacy (file management, installing software)
- Ability to type and use a keyboard efficiently
- Willingness to struggle — this course teaches through problem-solving

### Not Required

- ❌ No prior programming experience needed
- ❌ No prior web development knowledge needed
- ❌ No prior design skills needed
- ❌ No math beyond basic arithmetic

## 🔧 Initial Setup

### Create Your Project Folder

```bash
mkdir ecommerce-project
cd ecommerce-project
```

### Initialize Git

```bash
git init
git branch -M main
```

### Create Your First File

```bash
touch index.html
```

You're ready for [Module 01 →](./modules/module-01-html-structure/)
