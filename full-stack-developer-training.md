# FULL STACK DEVELOPER TRAINING Syllabus

## Web Foundations

- How the web works: browsers, servers, HTTP, DNS
- HTML5 semantic structure, forms, accessibility
- CSS3 layout, Flexbox, Grid, responsive design
- Mobile-first design and media queries
- Setting up VS Code, Git, and your dev environment

## Frontend Development

- Advanced CSS techniques and animations
- Tailwind CSS for utility-first styling
- Component-based UI design
- Responsive layouts and design systems
- Browser DevTools and debugging

## JavaScript Programming

- Variables, data types, operators, conditions
- Functions, scope, closures, higher-order functions
- Arrays, objects, destructuring, spread/rest
- DOM manipulation and event handling
- Async JavaScript: callbacks, Promises, async/await
- Fetch API and working with JSON

## React Development

- React components, JSX, props and state
- React Hooks: useState, useEffect, useContext, useRef
- React Router for SPA navigation
- Forms, controlled components, validation
- State management patterns
- Calling REST APIs from React

## Backend Development

- Node.js fundamentals and the module system
- Express.js routing and middleware
- Building REST APIs with Express
- Request validation and error handling
- Environment variables and configuration
- Authentication with JWT and password hashing

## Database & APIs

- MongoDB collections, documents, queries
- Mongoose schemas, models, and relationships
- SQL basics: SELECT, JOIN, INSERT, UPDATE
- CRUD operations end-to-end
- Connecting React frontend to Node backend
- API testing with Postman

## Deployment & Portfolio

- Git workflows, branches, and pull requests
- Hosting frontend on modern platforms
- Deploying Node.js APIs and databases
- Domain, HTTPS and environment configuration
- Building a strong GitHub portfolio
- Writing impressive READMEs for projects

## Career Preparation

- Resume building for full stack developer roles
- LinkedIn profile optimization
- Mock interviews — technical and HR
- Coding interview problem solving
- Explaining your projects with confidence
- Job search strategy and follow-ups
