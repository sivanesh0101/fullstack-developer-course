# ✅ Module 01 — Self-Assessment Checklist

Use this checklist to verify you've understood the concepts from this module before moving on.

---

## HTML Fundamentals

- [ ] I can create a valid HTML5 document from memory
- [ ] I understand what `DOCTYPE`, `<head>`, and `<body>` do
- [ ] I know the difference between `<head>` content and `<body>` content
- [ ] I can explain what meta tags do and why they matter

## Semantic HTML

- [ ] I can explain the difference between `<div>` and `<section>`
- [ ] I know when to use `<article>`, `<aside>`, `<header>`, `<footer>`
- [ ] I understand why semantic HTML matters for accessibility and SEO
- [ ] I can identify the correct semantic element for any content type

## Forms

- [ ] I can build a form with different input types
- [ ] I understand HTML validation attributes (`required`, `minlength`, `pattern`)
- [ ] I know the difference between `GET` and `POST` methods
- [ ] Every input in my forms has a corresponding `<label>`

## Images & Media

- [ ] I can add images with proper `alt` text
- [ ] I understand `width`, `height`, and `loading="lazy"`
- [ ] I know when to use `<picture>` vs `<img>`
- [ ] I can explain the difference between decorative and informative images

## Navigation & Links

- [ ] I can create internal, external, and anchor links
- [ ] I know when to use `target="_blank"` and `rel="noopener noreferrer"`
- [ ] I can build a breadcrumb navigation
- [ ] I understand the difference between `<a>` and `<button>`

## Tables & Lists

- [ ] I know when to use `<table>` vs CSS Grid for layout
- [ ] I can build an accessible table with `<thead>`, `<tbody>`, and `scope`
- [ ] I understand the difference between `<ul>`, `<ol>`, and `<dl>`
- [ ] I can create a product comparison table

## Accessibility

- [ ] I can navigate my entire site using only the keyboard
- [ ] I've added a skip navigation link
- [ ] All my images have appropriate alt text
- [ ] I understand ARIA labels and when to use them
- [ ] My Lighthouse accessibility score is 90+

---

## Project Checkpoint

By the end of Module 01, you should have:

- [x] `index.html` — Complete homepage with header, nav, hero, products, footer
- [x] `login.html` — Login form with validation
- [x] `signup.html` — Signup form with validation
- [x] `product.html` — Product detail page with specs table
- [x] Proper semantic HTML throughout
- [x] Accessible markup with ARIA labels
