# Module 01 — HTML Structure

## 🎯 Build the Amazon Homepage Skeleton

**Week 1** · Beginner · 8 Tasks

---

## The Pain Point

> "I need to build a web page. Where do I even start?"

You've seen Amazon, Flipkart, Netflix — beautifully designed websites with products, navigation, search bars, and footers. But when you open a blank file, you see... nothing.

This module answers the most fundamental question in web development: **How do you build the structure of a web page?**

No CSS. No JavaScript. No frameworks. Just **HTML** — the skeleton that every website on the internet is built on.

---

## What You'll Build

By the end of this module, you'll have a complete HTML-only clone of the Amazon homepage:

- ✅ Navigation bar with search
- ✅ Hero banner section
- ✅ Product category grid
- ✅ Product cards with images and details
- ✅ Login and signup forms
- ✅ Footer with links and information
- ✅ Fully accessible markup

It won't look pretty yet (that's Module 02). But it will have **every piece of content** in the right place.

---

## Learning Objectives

After completing this module, you will be able to:

- [ ] Create a valid HTML5 document from scratch
- [ ] Use semantic HTML elements to structure content meaningfully
- [ ] Build forms with proper input types and validation
- [ ] Add images with accessibility attributes
- [ ] Create navigation with proper link structures
- [ ] Understand the difference between block and inline elements
- [ ] Write accessible HTML that works with screen readers

## Key Concepts

### Why HTML First?

Every website — from a simple blog to Netflix — starts as HTML. Even React components compile down to HTML. Understanding HTML deeply means understanding the web deeply.

### Why No CSS Yet?

If you add CSS on Day 1, you'll focus on making things "look nice" and skip understanding **why** elements exist. By building ugly-but-correct HTML first, you'll appreciate CSS when it arrives in Module 02.

### Why Amazon?

Amazon's homepage has almost every HTML element you'll ever need:
- Navigation bars
- Search forms
- Image grids
- Product cards
- Lists and tables
- Footer links
- Accessibility features

If you can structure Amazon, you can structure anything.
