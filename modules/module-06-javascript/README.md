# Module 06 — JavaScript

## 🎯 Making It Interactive

**Week 6** · Intermediate · 11 Tasks

---

## The Pain Point

> "The Add to Cart button does nothing. How do I make things happen when users click?"

Your ecommerce site looks beautiful. But it's a lifeless brochure. Click "Add to Cart" — nothing happens. Search for a product — nothing happens. JavaScript gives your site a **brain**. It makes buttons work, data flow, and users interact.

---

## What You'll Build

- ✅ Working "Add to Cart" with quantity and total
- ✅ Real-time product search and filtering
- ✅ Category-based product sorting
- ✅ Cart data persisted in LocalStorage
- ✅ Products loaded from an external API

## Key Philosophy

We don't start with "What is a variable?" We start with "I need a working Add to Cart button." Every JavaScript concept is introduced because the project needs it — not because a textbook says so.
