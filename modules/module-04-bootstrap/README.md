# Module 04 — Bootstrap

## 🎯 Rapid UI with Reusable Components

**Week 4** · Beginner · 5 Tasks

---

## The Pain Point

> "I need 100 product cards, a responsive navbar, modals, forms, alerts, badges... I keep writing the same CSS over and over."

You've been writing custom CSS for every component — cards, buttons, forms, navigation. It works, but it's slow. Every new component requires starting from scratch. Professional teams use **UI frameworks** for pre-built, tested, responsive components.

**Bootstrap** gives you a library of ready-to-use components so you can build faster.

---

## What You'll Build

- ✅ Responsive grid layout with Bootstrap's 12-column system
- ✅ Pre-built components: cards, modals, navbars, forms
- ✅ Complete ecommerce page rebuild using Bootstrap
