## The Pain Point

> "Refresh the page... all the data is gone."

Your API stores products in a JavaScript array. When the server restarts, everything resets. **Databases** solve this by persisting data permanently. MongoDB stores data as JSON-like documents — a natural fit for JavaScript developers.
