## 🎯 Building the Backend

## The Pain Point

> "Products are stored in a JavaScript array. What do real companies do?"

Your React frontend fetches products from a fake API. Real ecommerce platforms have their own backend — an API they control, connected to a database. **Node.js** lets you write server-side code in JavaScript, and **Express** makes building APIs simple.
