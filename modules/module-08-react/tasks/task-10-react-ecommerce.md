# Task 10 — React Ecommerce

## 🎯 Objective
Build the complete ecommerce SPA with React, bringing together all concepts from this module.

---

## What You'll Build

- ✅ Component-based architecture (Header, ProductCard, CartPanel, Footer)
- ✅ Client-side routing (Home, Products, Product Detail, Cart, Login)
- ✅ Global state with Context API (cart, theme)
- ✅ Server state with TanStack Query (products from API)
- ✅ Form validation with React Hook Form + Zod
- ✅ TypeScript throughout (TSX)
- ✅ Responsive design with Tailwind CSS
