# Module 08 — React

## 🎯 Component-Based Architecture

**Week 8** · Intermediate · 10 Tasks

## The Pain Point

> "I'm writing 100 `<div class='card'>` blocks by hand. There has to be a better way."

Your JavaScript generates product cards dynamically. But the code is messy — HTML strings inside JS, manual DOM manipulation, no reusable structure. **React** introduces components: self-contained, reusable UI building blocks.
