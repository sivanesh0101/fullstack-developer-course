## The Pain Point

> `calculate(100, "abc")` — "Why didn't JavaScript stop me from passing a string to a number function?"

Your JavaScript code works... most of the time. But occasionally, bugs slip through — wrong data types, misspelled property names, functions receiving unexpected values. JavaScript doesn't catch these until runtime. **TypeScript** catches them at write-time.
