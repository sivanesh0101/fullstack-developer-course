# Task 05 — Tailwind Ecommerce

## 🎯 Objective
Rebuild the complete ecommerce homepage using only Tailwind CSS utility classes.

---

## Instructions

Build the full page — navbar, hero, categories, product grid, footer — using Tailwind. Compare the experience with custom CSS and Bootstrap.

### Your Four Versions

| Version | Approach | Time | Customization | File Size |
|---------|----------|------|---------------|-----------|
| Module 01 | Raw HTML | — | N/A | Smallest |
| Module 02 | Custom CSS | Longest | Full control | Medium |
| Module 04 | Bootstrap | Fast | Limited | Largest |
| Module 05 | Tailwind | Fast | Full control | Smallest (purged) |

### Reflection Questions

1. Which approach did you enjoy most?
2. Which would you choose for a client project?
3. Which gives the best balance of speed and customization?

---

## ✅ Expected Output

A fully custom-designed ecommerce homepage built entirely with Tailwind utility classes — no separate CSS file needed.
