# Module 05 — Tailwind CSS

## 🎯 Custom Design with Utility Classes

---

## The Pain Point

> "Bootstrap sites all look the same. I want a custom design, but I don't want to write 1000 CSS classes from scratch."

Bootstrap is fast, but opinionated. Every Bootstrap site has that "Bootstrap look." You want the speed of a framework with the flexibility of custom CSS. **Tailwind CSS** gives you utility classes that let you build completely custom designs without writing a single line of CSS.
