**Week 3** · Beginner · 4 Tasks

---

## The Pain Point

> "The client wants dark mode. I'd have to change colors in 200 places..."

Your ecommerce site looks great. Then the client says: "Can we add a dark mode toggle?"

You open your CSS file. There are 200+ color values scattered everywhere. Changing them all would take hours — and you'd probably miss a few. There **has** to be a better way.

**CSS Variables** solve this by defining colors once and referencing them everywhere. Change one variable, and the entire site updates instantly.
