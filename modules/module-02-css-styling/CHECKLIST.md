# ✅ Module 02 — Self-Assessment Checklist

Use this checklist to verify you've mastered CSS styling before moving on.

---

## CSS Selectors & Specificity

- [ ] I can target elements using class, ID, and attribute selectors
- [ ] I understand specificity and can predict which rule wins
- [ ] I know when to use classes vs IDs
- [ ] I can use combinator selectors (descendant, child, sibling)

## Box Model

- [ ] I can explain the box model (content → padding → border → margin)
- [ ] I always use `box-sizing: border-box`
- [ ] I know the difference between `margin` and `padding`
- [ ] I understand margin collapsing

## Flexbox

- [ ] I can create horizontal and vertical layouts with Flexbox
- [ ] I understand `justify-content` and `align-items`
- [ ] I can use `flex: 1` to fill remaining space
- [ ] I can build a header with spaced elements

## CSS Grid

- [ ] I can create a responsive product grid with `auto-fill` and `minmax`
- [ ] I understand `grid-template-columns` and `grid-template-rows`
- [ ] I can use grid template areas for page layout
- [ ] I can make elements span multiple rows/columns

## Positioning

- [ ] I understand `static`, `relative`, `absolute`, `fixed`, and `sticky`
- [ ] I can create a sticky navigation bar
- [ ] I can position badges and overlays on product cards
- [ ] I understand `z-index` and stacking contexts

## Responsive Design

- [ ] I build mobile-first with `min-width` media queries
- [ ] I can make images responsive with `max-width: 100%`
- [ ] I know common breakpoints for phones, tablets, and desktops
- [ ] I test my designs in Chrome DevTools device mode

## Pseudo-classes & Elements

- [ ] I can create hover and focus effects
- [ ] I understand `:nth-child`, `:first-child`, `:last-child`
- [ ] I can use `::before` and `::after` for decorative content
- [ ] I know the difference between pseudo-classes and pseudo-elements

## Animations

- [ ] I can create smooth transitions on hover
- [ ] I can write `@keyframes` animations
- [ ] I understand `transform` properties (scale, rotate, translate)
- [ ] I respect `prefers-reduced-motion` for accessibility

---

## Project Checkpoint

By the end of Module 02, your site should have:

- [x] Professional styling with colors, typography, and spacing
- [x] Flexbox-powered header and navigation
- [x] CSS Grid product card layout
- [x] Responsive design (mobile, tablet, desktop)
- [x] Hover effects and smooth transitions
- [x] Sticky navigation bar
- [x] Sale badges on product cards
- [x] Loading spinner animation
