## How to Use Each Module

Every module contains:

```
module-XX-name/
├── README.md          ← Start here: pain point, objectives, overview
├── tasks/
│   ├── task-01-*.md   ← Hands-on exercises (do these in order)
│   ├── task-02-*.md
│   └── ...
└── CHECKLIST.md       ← Self-assessment: "Can I do X?"
```

1. **Read the README** — Understand the problem this module solves
2. **Complete the tasks** — Hands-on exercises, in order
3. **Check yourself** — Use CHECKLIST.md to verify understanding
