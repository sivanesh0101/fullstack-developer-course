# 🚀 Full Stack Developer Training

### Build a Production-Ready Ecommerce Platform from Scratch

> Every technology is introduced exactly when the project needs it. You'll experience **why** HTML, CSS, JavaScript, TypeScript, React, Node.js, databases, authentication, deployment, and DevOps exist — by solving real engineering problems instead of memorizing isolated syntax.

---

## 🧠 Teaching Philosophy

This is not a typical course that teaches technologies in the order they exist.

**We teach technologies in the order students feel the pain.**

You won't learn TypeScript because someone tells you to. You'll learn it because JavaScript starts breaking your project. You won't learn React because it's popular. You'll learn it because writing 100 product cards by hand becomes unbearable.

> **Problem first. Technology second. Always.**

📖 [Read the full methodology →](./METHODOLOGY.md)

---

## 🏗️ One Project. Sixteen Weeks. Zero Disconnected Tutorials.

Instead of building throwaway mini-projects, you evolve **one ecommerce platform** from a plain HTML page to a production-deployed, containerized, AI-enhanced application.

```
Week 1  → HTML skeleton
Week 4  → Fully styled with CSS
Week 6  → Interactive with JavaScript
Week 8  → Component-based with React + TypeScript
Week 10 → Full-stack with Node + MongoDB
Week 13 → Tested and payment-ready
Week 16 → Deployed, dockerized, production-grade
```

By Week 16, you'll look back at Week 1 and see your own transformation.
